🚀1. First-time setup

The very first visit to your CoinCache URL shows a one-time Setup page.

  1. Enter your name, email, and a password (at least 8 characters). This becomes the admin account.
  2. Submit — CoinCache seeds the default categories and a Cash account, and signs you in straight away.
💡
The Setup page locks itself after this first account is created — nobody else can ever use it, even if they find your URL.

➕2. Recording an expense or income

  1. Tap the red − button for an expense, or the green + button for income.
  2. Type the amount on the keypad. You can calculate as you go — for example 120+80×2 — and press = (or the bottom button) to evaluate.
  3. Optionally set the account, date, or a note.
  4. Tap Choose category, then tap a category in the icon grid.

That's it — the record saves the moment you tap the category. Two taps for a plain expense.

✏️3. Editing & deleting

  1. Tap any record in the list — the same dialog opens, pre-filled with its values.
  2. Change anything you like (amount, account, date, note), then re-pick a category to save.
  3. Or tap 🗑️ to delete the record instead.

📅4. Periods & navigation

  • Use the tabs Day Week Month Year All to pick a period.
  • The ‹ and › arrows move to the previous or next period.
  • Weeks start on Monday.
  • "Today" follows the timezone set in Settings → Preferences, so day boundaries match your life, not the server clock.

🔍5. Searching

The search box above the Records list filters the current period. It matches against the category name, the note, and the account name — type taxi, birthday, or Bank and only matching records remain.

🏦6. Accounts & transfers

  1. Go to Settings → Accounts to add an account (name, icon, initial balance), edit an existing one, or archive one you no longer use.
  2. To move money between accounts, tap the ⇄ button next to the account picker and enter the amount.
💡
Transfers change account balances but never count as income or expense, so your donut chart and stats stay honest.

🗂️7. Categories

  • Manage them in Settings → Categories.
  • Add your own with any emoji and a color.
  • Archiving a category hides it from the keypad grid without touching your history — old records keep it.

📥8. Importing your old data

  1. In your old expense app, look for a Data backup / Export to CSV option.
  2. In CoinCache: Settings → Data → choose the file → Import CSV.

The importer auto-detects the delimiter, decimal style, and date order. Unknown categories and accounts are created automatically, so nothing is lost. Imports go into your own space only.

⚠️
If the file is ambiguous about date order, the importer assumes Day/Month/Year and shows a warning — if dates look wrong afterwards, re-import with the manual override. Skip duplicates makes re-imports safe: rows already in CoinCache are skipped, not doubled.

📤9. Exporting

Settings → Data → Export all records (CSV) downloads everything in a standard column layout (date, account, category, amount, currency, converted amount, currency, description) — so your data is portable to any other tool, forever.

👨‍👩‍👧10. Family members

Admin only.

  1. Go to Settings → Family & security → Add family member, and set a temporary password.
  2. They sign in with their email and the temporary password.
  3. They change it themselves in Settings → Change my password — this also signs out their other devices.

Each member gets their own private space, seeded with the default categories and a Cash account the moment they're created. Their accounts, categories, records, and preferences are entirely their own — the admin cannot see their data.

The admin can still reset any member's password from Settings → Family & security → Reset password — this signs out that member's other devices.

💡
Think of it as giving each person their own private app behind one login page — the admin only manages logins, never anyone else's records.

📱11. Install as an app

  • Android / Chrome: menu ⋮ → Add to Home screen / Install app.
  • iPhone / Safari: Share → Add to Home Screen.

CoinCache then opens fullscreen from its own icon, just like a native app.

⚙️12. Preferences

  • Currency: any 3-letter ISO code. Default is INR.
  • Timezone: default is Asia/Kolkata; it controls where your day, week, and month boundaries fall.

Both are per-user — your wife can use a different currency and timezone than you.
